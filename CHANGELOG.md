# Change Log

All notable changes to the Extension Wishlist extension are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0] - 2026-07-01

### Added

- Add extensions to a wishlist from the native Extensions view via a right-click **Add to Wishlist** action.
- Add extensions by their Marketplace ID (e.g. `esbenp.prettier-vscode`).
- Sidebar tree view in the Activity Bar listing saved extensions with a count badge.
- Open a wishlisted extension's page inside VS Code or in the Marketplace.
- "Installed" marker and inline **Uninstall** action for wishlisted extensions that are installed.
- Remove individual extensions or clear the entire wishlist.
- Wishlist stored in `globalState` so it roams across machines via Settings Sync.
